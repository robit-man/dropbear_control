# CAN adapter manifest intake

The tracked baseline contains no reviewed manifest submissions.

`submissions/` is reserved for exact, independently reviewed TWAI or MCP2515
hardware/clock/pin/transceiver/driver/binary/configuration/timing/TX-disable/
queue/timestamp/loss/error-policy evidence.

Listen-only and runtime-gateway purposes are separate records. A valid
manifest remains unselected and cannot enable physical I/O, support or motion.
