# Retired hand-authored parameter-set intake

JSON files in this directory are no longer consumed. Runtime plant parameter
sets may only be generated by `tools/generate_plant_parameter_sets.py` from:

- active source facts materialized by the independently reviewed
  plant-candidate lifecycle; and
- an independently accepted exact model/hardware/firmware/protocol/transport/
  control-mode applicability decision.

The generated registry and files live under
`generated/myactuator/plant/parameter_sets/`. Missing, conflicting, revoked or
semantically incompatible evidence removes the materialization. Family
defaults, hand-authored values, CAD-derived guesses and synthetic demo values
cannot enter the runtime plant registry.
