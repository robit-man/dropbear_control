MODEL BOUNDARY

Simulation, not certification

  • Task and bus timing are source-grounded.
  • Joint dynamics are stable synthetic approximations.
  • The browser uses the USD spanning tree for forward kinematics and retains all 27 closure constraints in its manifest; Isaac/PhysX remains authoritative for closed-loop dynamics.
  • The DevKit V1 geometry is a nominal clone envelope, because the installed PCB vendor/revision is not identified in source.
  • No commands leave the browser unless a future hardware transport is explicitly connected.
